# ISAP Cultural Event 2026

A promotional web app for the **ISAO Cultural Event** at the University of Missouri-Kansas City, scheduled for April 18, 2026.

## About

A celebration of global cultures featuring world cuisine, performances, educational booths, and artistic showcases (dance, music, fashion, poetry, visual art).

## Tech Stack

- **Streamlit** — Web framework
- **Pillow** — Image processing
- Custom CSS with radial gradient backgrounds and serif typography

## Setup

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Structure

```
├── app.py              # Main Streamlit application
├── requirements.txt    # Dependencies
└── images/             # Event promotional images
```
